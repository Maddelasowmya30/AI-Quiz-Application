
# 🧠 AI Quiz Application using Python

## Project Overview

AI Quiz Application is a Python-based interactive web application developed using Streamlit.

The application allows users to answer multiple-choice questions, calculate their final score, and receive personalized learning feedback based on their quiz performance.

The project uses Python data structures, functions, loops, conditions, and Streamlit to create a simple educational application.

This version does not use external APIs or API keys. The personalized feedback is generated using rule-based Python logic.

## Features

- Multiple-choice quiz questions.
- Multiple answer options.
- Interactive answer selection.
- Automatic score calculation.
- Percentage calculation.
- Personalized learning feedback.
- Topic-wise performance analysis.
- Correct and incorrect answer review.
- Quiz restart option.
- Web-based user interface.
- No external API required.

## How to Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd AI_Quiz_Application
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

## Deployment

This project can be deployed using Streamlit Community Cloud.

The main application file is `app.py`.

The dependencies are listed in `requirements.txt`.
